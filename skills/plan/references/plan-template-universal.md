# Universal Plan Template

Use the shared frontmatter and core sections first, then pick the body shape
that matches the mode.

## Shared Base

```markdown
---
title: <short descriptive title>
kind: universal
status: planned
mode: writing | strategy | trip | study | runbook | investigation | proposal
created: YYYY-MM-DD
updated: YYYY-MM-DD
repo: none
source_inputs:
  - <transcript, URL, note, request>
---

# <Title>

## Goal

## Context

## Constraints

## Approach

## Open Questions
```
